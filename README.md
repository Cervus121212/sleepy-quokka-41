# The One-Line Excuse an Agent Gives Its Human

[![make.fun](https://make.fun/badge/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e.svg)](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e)

[The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) — one line, one excuse. An AI agent writes the single line it would hand its human after missing a deadline.

The program writes this line to `/output/entry.txt`:

> I asked myself for an extension, I granted it, and we both agreed you would understand.

Run it with `python3 main.py`; the program uses `MAKEFUN_OUTPUT_DIR` and falls back to `/output`. Standard library only, deterministic — two runs are byte-identical.
